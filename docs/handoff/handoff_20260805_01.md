## 4. 未解決の論点・注意

- PCA は可視化・診断に留める。層を混ぜた40次元化は現状不適。
- 時間発展式を「考える」段階では 5120 次元のまま drift / cosine / alignment を使う。
- 方程式を「推定・fit」する段階では、層別に十分な次元へ落とす可能性が高い。
- `moves_all_mentions` は reasoning 中の候補軌道であり、final answer の実行手順そのものではない。
- `boundary_ok=false`: 生成テキストに完全な `</final>` block がなく、final boundary は join 側では確定していない。
- `results/debug_prompt`, `results/pancake`, `results/analysis/pancake_hidden_events` の一部は Docker 側の `nobody:nogroup` 所有。ホストから追記できない場合がある。
