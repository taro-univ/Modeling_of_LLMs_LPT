## 1. このセッションで決めたこと

- 代表軌道だけを選ぶpilotではなく、outcomeで事前選別しない分布datasetを取得する。
- 実現可能な `(N, min_moves)` 6 cellを各100 trials、合計600 trajectoriesとする。

```text
(3,3), (4,3), (4,4), (5,3), (5,4), (5,5)
```

- sample seedは固定plan順のglobal unique値 `1..600`。
- 取得条件は次で固定した。

```text
model: deepseek-ai/DeepSeek-R1-Distill-Qwen-14B
temperature: 0.6
repetition_penalty: 1.1
n_shot: 0
num_predict: 8192
early_stop: disabled
capture: generated token only, token:1, all 48 layers
hidden: float16, [T,48,5120]
storage: chunked HDF5, gzip, 64-token CPU buffer
```

- hidden類似度、PCA、drift/diffusion等は取得runnerに入れず、後続の解析側で行う。
- 生成文、token IDs、prompt、終了理由、Move/think/final span、reasoning/final別replay、
  version付きlabelsを保存し、後から失敗原因を再ラベリングできるようにした。
- cellごとに100 trials完了後、Drive上の全fileのsize/MD5を検証する。
  remote markerとlocal receiptが現在のcell manifest SHA-256に一致した場合だけ、
  明示flagでlocal cellを削除できる。

## 4. 帰宅後に最初に行うこと

### 4.1 Google Drive接続設定

GPU hostでrcloneをinstallし、リポジトリ外に認証を保存する。

```bash
rclone config
```

推奨値:

```text
remote name: pancake-drive
storage: Google Drive
scope: drive.file
root_folder_id: 空欄
Shared Drive: No
```

`drive.file` では、rcloneが作る専用folderだけを扱う。認証情報は通常
`~/.config/rclone/rclone.conf` に保存し、repositoryに置かない。

接続と容量を確認する。

```bash
rclone lsd pancake-drive:
rclone about pancake-drive:
```

### 4.2 小容量Drive integration test

```bash
python3 runners/pancake_drive_integration_test.py \
  --remote-root pancake-drive:LLM_LPT/full_hidden_v1_integration_test
```

次が出れば接続テスト合格。

```text
[PASS] upload, remote MD5, resume, re-download SHA-256
```

test remoteは目視確認用に自動削除しない。

## 5. Drive接続後の順序

1. GPU環境に `requirements.txt` を反映し、HDF5実file testのskipを解消する。
2. N3 schema smokeを取得し、Drive転送まで確認する。
3. N5 stress smokeを取得し、速度・容量・RAM/VRAM・Drive転送を確認する。
4. 両smoke合格後だけ、本実験600 trialsを小さいcellから開始する。

```text
N3/mm3 -> N4/mm3 -> N4/mm4 -> N5/mm3 -> N5/mm4 -> N5/mm5
```

smokeコマンド:

```bash
python3 runners/pancake_full_hidden_dataset.py \
  --smoke schema \
  --remote-root pancake-drive:LLM_LPT/full_hidden_v1_smoke

python3 runners/pancake_full_hidden_dataset.py \
  --smoke stress \
  --remote-root pancake-drive:LLM_LPT/full_hidden_v1_smoke
```

## 6. Stop rule

- Driveの小容量integration testが通るまでGPU smokeを始めない。
- N3 schema smokeが落ちたらN5 stress smokeへ進まない。
- N5 stress smokeが落ちたら本実験へ進まない。
- remoteのsize/MD5/marker/manifestが一致しなければremote verifiedと扱わない。
- remote verified receiptと現在のcell manifest SHA-256が一致するまでlocal削除しない。
- quota、通信、hash、容量のいずれかで失敗したらlocalを保持し、次cellへ進まない。
