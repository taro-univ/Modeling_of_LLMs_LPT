## 4. 未解決の論点・注意

- `loop_trap` 暫定しきい値 0.3 は敏感すぎる。N=3 成功例にも立つため、排他的 failure label ではなく補助フラグとして扱う。
- `search_goal=true` は「生成中の全 Flip mention を連続実行したとき一度でも goal を通る」という意味で、final answer の正しさとは別。
- `length_stop` は一律 failure にしない。`goal_reached_all_mentions=true` かつ `moves_final=[]` は budget-censored trial 候補。
- N=5 で `num_predict=8192` を使う場合、N 効果と token budget 効果を混ぜないよう、4096 条件と明示的に分けて扱う。
- `results/debug_prompt/...` は Docker 側で `nobody:nogroup` 所有になる場合がある。summary 書き出しで PermissionError が出たら Docker 内で実行する。
