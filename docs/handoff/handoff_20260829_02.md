hidden rowの解釈:

```text

b == generated token countの場合、after-phase rowは保存されていない
```

## 3. annotation ruleで固定した重要な区別

primary label:

```text
setup
plan
state_simulation
move_proposal
verification
backtracking
self_correction
loop_like
final_commit
```

特に次を混同しない。

- `plan`: 複数手にわたる戦略、algorithm、subgoal順序の設定・変更。
- `move_proposal`: 現在地点から具体的な1手または短いFlip候補を出す局所探索。
- `state_simulation`: 候補手を適用した後のstackを実際に計算・追跡する。
- `backtracking`: 現在の探索枝を明示的に捨て、以前の状態または別戦略へ戻る。

seed 528のsegment 8、char span `[1724, 1946)`は、人間レビューにより
`plan`から`move_proposal`へ修正した。修正理由とharness結果は正本ruleの修正ログにある。

## 6. 明日読む論文

各分野のランキング1位を印刷済み。明日2026-08-30は、この2本を読むところから始める。

### LLM / AI

Lihao Sun et al., **LLM Reasoning as Trajectories: Step-Specific Representation Geometry and
Correctness Signals**, ACL 2026.

```text
https://aclanthology.org/2026.acl-long.1237/
```

現在の研究との接点:

- reasoning stepごとのrepresentation subspace。
- 正解・不正解軌道が後半で分岐するという観測。
- layer depthに伴うstep-specific geometryの分離。
- 中間軌道からの正誤予測とtrajectory intervention。

注意:

- 論文のstepは明示的な`Step`形式に基づく。Pancakeの人手による意味phaseとは同一ではない。
- 手法と検証設計を借り、phase ontology自体は輸入しない。

### 他分野 / 粗視化

Andreas Mardt et al., **VAMPnets for Deep Learning of Molecular Kinetics**,
Nature Communications 2018.

```text
https://www.nature.com/articles/s41467-017-02388-1
```

現在の研究との接点:

```text
高次元trajectory
-> 遅い集団変数
-> 少数のfuzzy metastable state
-> Markov / Koopman transition model
-> 長時間予測の定量検証
```

特に確認する概念:

- lag time。
- implied timescale。
- Chapman-Kolmogorov test。
- fuzzy state assignment。
- coarse-graining後のMarkov性。
- 5-state modelと40-state MSMの比較方法。

## 8. phase同期後の解析候補

8 trialの同期完了後も、現象論を先に固める。

優先候補:

- phaseごとのcommon PCA-n90 centroidと分散。
- phase開始から終了までのdisplacementとpath length。
- phase境界前後のjump norm、速度、方向変化。
- 同一phase内距離とphase間距離。
- matched set内で、success/failure軌道が分岐し始める最初のphase。
- trial単位のpermutationまたはbootstrap。tokenを独立標本として扱わない。

Markov chain、SLDS、SINDyは、軌道数を増やし、phase境界と低次元座標の安定性を確認した後に扱う。
