## 1. このセッションでやったこと

- Pancake debug sweep 用 shell script を追加した。
  - `runners/scripts/run_pancake_debug_sweep.sh`
  - default 条件:
    - `MODEL_ID=deepseek-ai/DeepSeek-R1-Distill-Qwen-14B`
    - `NS="3 4"`

    - `TRIALS=5`

    - `SEED_BASE=1`
  - 固定出力先:
    `results/debug_prompt/pancake/<model_slug>/N<N>_seed<seed>_np<num_predict>_T<T_label>/`
  - 既存 `debug.json` があれば skip する。
- モデルを1回だけロードして sweep する batch runner を追加した。
  - `runners/pancake_debug_sweep.py`
  - `run_pancake_debug_sweep.sh` は default で `REUSE_MODEL=1` としてこの runner を使う。
  - 最初は `debug_prompt.py` を run ごとに起動する方式で始めたが、14B モデルを毎回ロードして遅すぎたため停止し、batch runner に切り替えた。
- `analysis/analyze_pancake_debug.py` を整備した。
  - 既存の単発 `debug.json` 詳細解析を残しつつ、ディレクトリ集計に対応。
  - N/T ごとの以下を出力:
    - `final_accuracy`
    - `goal_reached_all_mentions`
    - `no_final`
    - `length_stop`
    - `loop_trap`
    - `repeated_state_ratio`
  - `--run-dir-glob` を追加し、今回の固定命名 run だけを集計できるようにした。
- `loop_trap` の暫定定義を実装した。
  - `repeated_state_ratio = repeated_state_count / max(1, len(moves_all_mentions))`
  - `loop_trap = repeated_state_ratio >= 0.3`
- Docker/GPU で Pancake small sweep を30本まで実行した。
  - 予定: 50 runs
  - 完了: 30 runs
  - 実行済み:
    - `N=3`, T=0.0/0.3/0.6/0.9/1.0, 各5 seeds: 完了
    - `N=4`, T=0.0, 5 seeds: 完了
  - 未実行:
    - `N=4`, T=0.3/0.6/0.9/1.0, 各5 seeds: 残り20本
- 30本時点の集計を書き出した。
  - `results/debug_prompt/pancake/deepseek-r1-distill-qwen-14b/pancake_debug_summary_30.csv`
  - `results/debug_prompt/pancake/deepseek-r1-distill-qwen-14b/pancake_debug_summary_30.json`

## 4. 未解決の論点・注意

- `loop_trap` 暫定しきい値 0.3 はかなり敏感。
  - `N=3` の成功軌道でも loop_trap 率が 1.0 になっている。
  - final success と loop_trap が同時に立つため、発表用 label としては再調整が必要。
- `final_accuracy` は「goal 到達」判定で、最短手数一致ではない。
  - `N=4, T=0.0, seed=1/2` では4手提出でも final success になっている。
  - 最短解制約を見るなら別指標 `optimal_final` などを追加する。
- `results/debug_prompt/...` は Docker 側で `nobody:nogroup` 所有。
  - ホスト側 Python から同じ場所へ summary を書くと PermissionError になる。
  - summary 書き出しは Docker 内で実行する。
- `analysis/analyze_pancake_debug.py` をディレクトリに対して走らせると、過去の timestamp 形式 debug も混ざる。
  - 今回の sweep だけ見る場合は必ず `--run-dir-glob 'N*_seed*_np4096_T*'` を付ける。
- sweep 実行中に手動 interrupt したが、30本目の `debug.json` 保存後にプロセス停止済み。
