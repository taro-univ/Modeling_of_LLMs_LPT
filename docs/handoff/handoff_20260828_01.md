## 4. 未解決の論点・注意

- 主解析はlayer 48だけで、層横断の現象ではない。
- random reasoning nullは長さを統制するが、token列・final tag・自然文phaseを統制していない。
- final cosineの高さにはhidden空間のanisotropyや定型final文の影響が残りうる。
- aligned cosineは同長finalだけを比較する。異長比較はFréchetへ分けており、heatmapの空欄は欠損ではなく比較不能を示す。
- linear CKAは同長代表軌道でほぼ1となり、この設定では識別力が低い。主証拠ではなく補助指標として扱う。
- Fréchet距離はfinal長の違いに強く反応するため、min_moves別の長さ差と形状差を混同しない。
- PCAのPC1--PC3は約38%しか説明しない。3次元図だけで高次元軌道全体を主張しない。
- 複雑度相関は6 cellしかないため記述的可視化であり、検定的結論に使わない。
- N5/mm3, mm4, mm5にはclosed finalがないtrialがそれぞれ3, 14, 13件ある。
  主解析のfinal cohortは各cellの`success_final`のみ。
