# P(q) moments ベース相分類器

## 1. 目的・動機

現行の相分類は early_stop ラベル率とスカラー `q_EA` 閾値に依存しており、
`docs/phase_classification_review.md` で物理的に不合格と判定済みである。
本 SPEC では、レプリカ間 overlap 分布 $P(q)$ の moments と形状を主情報として、
Ordered / Spin Glass / Paramagnetic / Transitional / Undetermined を分類する解析器を設計する。

対応する論点：

- `open_questions.md` U2: SG 相の判定基準
- `research_state/hypotheses.md` H3: move loop ↔ 局所安定状態
- `SPEC-2026-05-21-001`: `stagnation_after_move` は SG 寄り補助シグナルだが統計不足

この SPEC のゴールは、ハミルトニアン fitting や Landau / REM モデリングに渡せる
相図を、早期終了ラベルだけでなく hidden state のレプリカ構造から作ることである。

## 2. 物理的要件【physics-agent レビュー案】

### 2.1 保存則・対称性の要件

- レプリカ定義は Round 1 決定に従う：
  同一プロンプト・同一 $N$・同一 $T$・異なる乱数シードの試行をレプリカとする。
- **overlap はレプリカ交換 $\alpha \leftrightarrow \beta$ に対して対称**：$q^{\alpha\beta} = q^{\beta\alpha}$。
  実装は `(i, j)` with `i < j` のループで off-diagonal pair のみを使う。
  **self-overlap $q^{\alpha\alpha} = 1$ は P(q) 構成に含めない**（右端を artificial に膨らませるため）。
- 同一 (model, N, T, layer, sweep_type) 条件内だけで $P(q)$ を構成する。
  異なる温度・サイズ・モデルの hidden state を同一分布に混ぜない。
- `think_budget` は物理的相ではなく測定打ち切りなので、相判定の分母から除外する。

### 2.2 hidden state の等方化

raw hidden state は共通方向 $\mu$ に支配され、cosine overlap が高くなりやすい。
スピングラス理論の平均ゼロスピンとの対応を作るため、以下の前処理を必須にする。

1. **同一 model / layer の全試行（全 $N, T$）で** hidden state 平均 $\mu$ を推定する
   （cell-local ではなく全条件 union — Ordered 相の整列シグナルを誤除去しないため。2026-05-22 user 確定）
2. $h' = h - \mu$ で centering する
3. PCA/ZCA whitening または top-k common direction removal で異方性を抑える
4. 正規化後の $\tilde{h}$ で $q^{\alpha\beta}$ を計算する

初期実装では `center`, `remove_topk`, `zca` を CLI で切り替え可能にし、デフォルトは
`center + remove_topk(k=3)` とする。ZCA は条件数が悪い場合の regularization を必須にする。
`k` は CLI 引数 `--topk` で外出し（デフォルト 3）。感度解析（$k=0,1,3,5,10$）を出力に含める。

**default layer: `layer_mid`**（depth 50%。task-specific すぎず低レベルすぎない中間層。2026-05-22 user 確定）。
CLI で `--layer {layer_top,layer_mid,layer_low}` として切り替え可能にする。
将来は 3 層並列出力を検討（open_questions U1-i と連動）。

### 2.3 overlap と moments

各試行 $\alpha$ の時間平均 hidden state を

$$
\bar{h}^{(\alpha)} = \frac{1}{T_\alpha} \sum_t \tilde{h}^{(\alpha)}_t
$$

とし、レプリカ間 overlap を

$$
q^{\alpha\beta} =
\frac{\bar{h}^{(\alpha)} \cdot \bar{h}^{(\beta)}}{\|\bar{h}^{(\alpha)}\| \|\bar{h}^{(\beta)}\|}
$$

で定義する。ただし $T_\alpha$（各レプリカの move ステップ数）は相に依存する（Ordered 相では短く、SG 相では長い傾向）ため、**$T_\alpha < T_{\min}$ のレプリカは除外**し `n_censored` に計上する。$T_{\min}$ は CLI 引数で外出し（デフォルト 1）。

分類器は少なくとも以下を出す。

| 量 | 意味 |
|---|---|
| `q_mean` | overlap 平均 |
| `q_var` | overlap 分散。非自己平均性・分布幅の代理 |
| `q_abs_mean` | $\|q^{\alpha\beta}\|$ の期待値。**Z2 対称性（$h \to -h$）を仮定したときの EA 振幅推定**。研究調査 (R1) により LLM 埋め込みに Z2 対称性の文献的根拠なし（centering 後も skewness は非ゼロのため）。この量は探索的記録に留め、`q_mean` と `q_var` を主情報とする。 |
| `q_tail_mass` | 高 overlap 領域の質量 |
| `q_bimodality_bc` | Sarle's Bimodality Coefficient $b = (g^2+1)/\kappa$（$g$: 歪度、$\kappa$: 尖度）。$b > 5/9$ で一様分布より双峰寄り（高感度・偽陽性多め） |
| `q_bimodality_dip` | Hartigan's dip statistic（p 値付き）。SG 文献でも使われる双峰性検定（高特異度）。bootstrap CI 付きで出力 |
| `n_effective` | `think_budget` を除いた有効試行数 |
| `q_mean_ci_95` | `q_mean` の 95% bootstrap CI（trials=25、pairs=300 での推定精度保証） |
| `q_var_ci_95` | `q_var` の 95% bootstrap CI（4 次 moment は N=300 で不確実性大） |

### 2.4 相分類の物理的制約

- Ordered: accuracy が高く、かつ $P(q)$ が低分散で高 overlap 側に集中する（Hopfield recall 相に対応）。
- Spin Glass: accuracy は低いが、$P(q)$ に有限幅・双峰性・高 overlap tail が残る（Hopfield SG 相に対応）。
- Paramagnetic: accuracy が低く、等方化後の $P(q)$ が $q \approx 0$ 近傍に単峰集中する（Hopfield PM 相に対応）。`pm_rate` は補助シグナルとして記録するが主判定条件には使わない（2026-05-22 user 確定）。
- Transitional: Ordered/SG/PM の判定指標が競合する境界セル。
- Undetermined: 有効試行数不足、hidden state 欠落、または指標不安定。

`stagnation_after_move` は主分類条件に入れず、SG 寄り補助特徴として記録する。

**Hopfield/AGS 相図との対応**：Amit-Gutfreund-Sompolinsky (1987) の Hopfield 模型相図（recall / SG / PM）は、本 SPEC の Ordered / SG / PM に概念的に対応する。AGS の $P(q)$ は recall 相でデルタ的ピーク（$q \approx \pm m$）、SG 相で双峰（$q \approx \pm q_{\mathrm{EA}}$）、PM 相で $q=0$ 単峰となる。ただし AGS は Ising spin の $\mathbb{Z}_2$ 対称性を前提としており、LLM hidden state への転用は Z2 対称性の成否に依存する（research 調査 R1 により現状根拠なし）。したがって本 SPEC の $P(q)$ は「AGS 類似の構造を経験的に探索する」立場をとり、双峰の存在を「SG 的挙動の傍証」として扱う。

**有限サイズ効果の注意**：本分類器が対象とする $N \in [2, 6]$ は熱力学極限から遠く、相境界の正確な位置や $T_c(N)$ スケーリング指数の決定には有限サイズスケーリング解析（Binder cumulant 等）が必要。本分類器の出力は $N$ と $T$ を所与とした暫定分類であり、相境界自体は別途スケーリング解析で確定する。

### 3.2 novelty 観点での位置づけ

既存の spin glass 研究は $P(q)$ を相判定の中心に置くが、LLM 推論軌道の hidden state を
レプリカとして扱い、reasoning failure mode と対応づける部分が本研究の novelty。
既存の representation anisotropy 研究は幾何補正を扱うが、補正後の overlap 分布を
SG/PM/Ordered 相分類に使う点は本研究固有。

- Parisi overlap の思想に合わせ、単一平均値ではなく分布幅・tail・双峰性を保存する。

## 4. アルゴリズム仕様【implementation-agent 設計案】

### 4.1 擬似コード / フロー

```
input: dirs, model_slug, layer, ns, ts, isotropy_method, topk, thresholds

for each condition (N, T):
    cond = load_condition(dirs, N, T, layer)  # analyze_integrated.py 版（複数 dir 対応）
    if cond is missing: mark undetermined

    usable_trials = exclude think_budget and missing hidden
    if len(usable_trials) < min_trials:
        mark undetermined

    H_trial = time-average each trial hidden state
    H_iso = isotropize(H_trial, method=isotropy_method, topk=topk)
    # topk は --topk CLI 引数で外出し（デフォルト 3）。マジックナンバー埋め込み禁止

    q_vals = all pair cosine overlaps over H_iso
    moments = compute_pq_moments(q_vals)
    label_rates = compute early_stop rates excluding think_budget
    acc = mean accuracy over effective trials

    phase = classify_from_moments(acc, moments, label_rates, thresholds)
    save cell metrics row

save metrics.csv / metrics.json
plot phase diagram
plot P(q) grid
plot threshold sensitivity
```

### 4.3 分類器の初期ルール案

初期実装では閾値を固定値として CLI / JSON で外出しし、後で感度解析する。

| phase | 初期条件案 |
|---|---|
| `ordered` | `accuracy >= acc_ordered_min` かつ `q_var <= ordered_var_max` かつ `q_tail_mass >= ordered_tail_min` |
| `spin_glass` | `accuracy < acc_ordered_min` かつ (`q_bimodality >= sg_bimodality_min` または `q_var >= sg_var_min` または `q_tail_mass >= sg_tail_min`) |
| `paramagnetic` | `accuracy < acc_ordered_min` かつ `q_mean <= pm_mean_max` かつ `q_var <= pm_var_max`（主判定は P(q) ベース。`q_abs_mean` と `pm_rate` は補助シグナルとして記録のみ・2026-05-22 user 確定） |
| `transitional` | 上記の複数条件が競合、または境界近傍 |
| `undetermined` | `n_effective < min_trials` または hidden state 欠落 |

変更点（physics-agent C2.4-b/c 指摘対応）：
- Ordered に `q_var <= ordered_var_max` を追加（一点集中 = low variance が Ordered の物理的本質）
- SG に `q_bimodality >= sg_bimodality_min` を追加（双峰性が SG の最重要シグニチャ）
- PM の `pm_rate` を暫定的に残すが補助シグナルとして注記（user 確認中）

注意：この閾値は物理的にまだ未確定。実装後、7B/14B の既存 sweep で閾値感度を必ず見る。

#### 確認結果

**[1] ファイル分割の妥当性 — 概ね適切、ただし `pq_metrics.py` の境界が曖昧**

- `isotropy.py`（等方化前処理）と `pq_phase_classifier.py`（相判定ロジック + CLI エントリ）の分離は単一責任原則に合致している。
- 問題は `pq_metrics.py` の責務範囲が仕様書内で定義されていない点。
  現行の `analyze_integrated.py::compute_pq` / `compute_qea` / `compute_autocorr` と完全に重複する計算関数が `pq_metrics.py` に入るのか、それとも `analyze_integrated.py` からの `import` のみで済ませるのかが不明確。
- 推奨：`pq_metrics.py` の責務を「等方化後の overlap 計算 + moments 集計（`q_var`, `q_tail_mass`, `q_bimodality` など、既存にない計算）」と明示し、既存の `_cosine` / `compute_pq` / `compute_qea` はそのまま `analyze_integrated.py` から import する形に限定する（後述 [2] と統一）。
  これにより `pq_metrics.py` は新規の moments 計算のみを担い、重複コードが生まれない。

**[2] 既存コードとの接続 — `load_condition` / `_cosine` の import は実現可能だが設計上の注意が必要**

- `stagnation_diagnostic.py:33` で `from analysis.analyze_integrated import _cosine, load_condition` を既に実施しており、import パターンとして実績がある。
- ただし `load_condition` は `analyze_integrated.py` 版（複数ディレクトリ対応）と `analyze_pq.py` 版（単一ディレクトリ対応）で**シグネチャが異なる**（引数 `dirs: list[Path]` vs `base_dir: Path`）。新分類器は `analyze_integrated.py` 版（複数 dir 対応）を import すべきであり、コード内コメントで明示すること。

**[3] CLI インターフェース — 拡張耐性は十分、ただし閾値 JSON の仕様が未定義**

- `isotropy_method` を `{center, remove_topk, zca}` で切り替える設計は適切。デフォルト `center + remove_topk(k=3)` は実装時に `k` を追加 CLI 引数 `--topk` として外出しすること（マジックナンバーの埋め込み回避）。

**[4] 出力仕様 — `results/analysis/` パスが既存パターンと乖離している**
