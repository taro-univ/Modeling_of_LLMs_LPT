# P(q) bimodality による accuracy 予測能力の検証

---

## 1. 目的・動機

**中心的な問い**：P(q) の bimodality は、accuracy 以外の情報を持つか？
すなわち、P(q) 統計量（分散・bimodality 係数・dip検定）が accuracy rate を
温度 T だけで説明する以上に予測できるか。

**動機**：  
現状の相図は「T を変えると accuracy が変わる」の高尚な言い方に見える可能性がある。
P(q) が独立した予測変数であることを示せれば、SG 秩序変数として実質的な意味を持つ。

**データ**：  
`results/hanoi/full_sweep/deepseek-r1-distill-llama-8b/` (N=2〜5, 13条件/N, 25 trials/cell)  
各 trial: `trial_NNN_hidden.npz` → `layer_mid` shape=(steps, 4096)

## 2. 物理的チェック【physics-agent のみ記入】

### 2.1 保存則・対称性の要件

- **レプリカ対称性の破れ (RSB)**: P(q) bimodality は RSB の証拠として解釈する。
  これは「異なる初期条件（trial）からの系が異なる純粋状態に収束する」を暗に仮定する。
  LLM では「初期条件」= 同一プロンプト、「純粋状態」= 生成パス。
  この対応が物理的に正当か？

- **自己平均性**: accuracy rate = 単一 (N,T) セルでの trial 平均 を秩序変数 m として扱う。
  真の熱力学極限でのみ自己平均性が成立するが、25 trials ではサンプル数が少ない。
  この有限サンプル効果が解析に与える影響は？

- **time-reversal / replica 交換**: P(q) の計算は trial 間の対称性（いつ誰と比べてもよい）を仮定する。
  LLM の generation は自己回帰的で時系列依存があるが、trial 間（異なるサンプリング）の比較は
  レプリカとして扱える？

### 2.2 秩序変数の定義の整合性

```
q_{ab} = (1/d) * sum_i  h^a_i * h^b_i  （コサイン類似度の形）

h^a = mean_{steps} layer_mid[step, :]  (trial a の隠れ状態の move-step 平均)
```

- この `h^a` の平均化（move-step 方向）が物理的に正当か？
  move-step ごとに隠れ状態は変化するので、平均は「軌跡の重心」を表す。
  SG 文脈で意味ある量か？

- layer_mid（depth 50% のレイヤ）の選択根拠：
  layer_top (最終層) vs layer_mid vs layer_low で P(q) の質が変わる可能性がある。
  今回は 3 層すべてで計算して比較する。

### 2.3 予測のメカニズム仮説（検証前に物理的整合性を確認）

**仮説 A（SG → 低 accuracy）**:  
bimodality が高い条件では「同じ問いに対して複数の異なる挙動パターンが存在する」（局所安定状態の共存）。
これが SG 相の signature であり、どの局所安定状態に落ちるかランダムであれば accuracy は低下する。

**仮説 B（bimodality の二峰が何を表すか）**:  
q≈0 グループ: 各 trial が全く異なる hidden space 領域を探索（disorder の典型）  
q≈q_EA グループ: trial 間が類似した attractor に収束（秩序または SG 的固定点）

accuracy が高い trial は q≈q_EA グループに属するか？  
それとも q≈0 グループに属するか？（= 「正解に到る道は一意で、他 trial とは異なる領域」）

**審査日**：2026-05-25（壁打ち内）
**判定**：承認 — Track B 実行可能

Section 2.1〜2.3 の各懸念について確認済み：

- **replica 対応**：同一プロンプトへの独立サンプリングをレプリカとして扱うことは許容範囲
- **自己平均性（25 trials）**：有限サンプル効果は存在するが、Section 6 の partial correlation 基準で管理可能

**継続確認事項**：move-step 数の不均一による h_mean バイアスは実行後に検証する。

## 3. 解析手順

### Step 1: P(q) 統計量の計算（各 (N,T) セル）

```python
for each (N, T) cell:
    # hidden state per trial
    H_trials = []
    for npz in sorted(trial_*.npz):
        h = npz['layer_mid']          # shape (steps, 4096)
        h_mean = h.mean(axis=0)       # shape (4096,) — move-step 平均
        H_trials.append(h_mean)
    
    # P(q): pairwise cosine similarity
    q_vals = [cosine(H_trials[i], H_trials[j]) 
               for i < j]             # n*(n-1)/2 = 300 pairs (n=25)
    
    # statistics
    q_mean   = mean(q_vals)
    q_var    = var(q_vals)
    q_bc     = sarle_bimodality_coefficient(q_vals)
    dip_pval = hartigan_dip(q_vals)
    q_ea     = mean(q_vals**2)**0.5   # Edwards-Anderson order parameter
```

### Step 2: accuracy との相関（条件レベル）

各 (N,T) セルの 4 統計量 vs accuracy rate:
- Pearson 相関係数 r と p 値
- scatter plot（N 別に色分け）
- partial correlation（T を control した後の bimodality vs accuracy）

### Step 3: trial レベル解析（within-cell）

N=3, T=0.2〜0.8 の中間 accuracy 条件で：

```
各 trial i のローカル q スコア:
  q_local_i = median(cosine(h_i, h_j) for j != i)

成功 trial（accuracy=1）の q_local 分布
失敗 trial（accuracy=0）の q_local 分布
→ Mann-Whitney U 検定
```

仮説：成功 trial は isolated（q_local が低い）か、conformist（q_local が高い）か？

### Step 4: 3 層比較

layer_top / layer_mid / layer_low で P(q) を計算し、
どの層が accuracy との相関が最も高いかを確認。

| 指標 | 合格（SG 仮説支持） | 棄却 |
