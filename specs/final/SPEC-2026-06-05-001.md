# ハノイ env のゴール／ポテンシャル対称化（B/C ペグ gauge 等価）

## 1. 目的・動機

ゴールペグ・パリティ交絡（2026-06-05 発見）の恒久対処。env `TowerOfHanoiEnv` のゴールが peg C にハードコードされていたため、モデルが暗記正準解を復唱する高温域で、偶数 N の完全最適解が peg B に積み上がり accuracy=0 と誤判定されていた。

physics-agent 審査（2026-06-05 ラチファイ）により、peg B/C は $S_3$ ペグ置換対称性で gauge 等価であり、秩序変数とポテンシャルを対称化すべきと確定。本仕様は env コードをこの対称化に合わせて修正する。既存 432 セルは保存済み move_texts から再計算済み（`research_state/symmetric_accuracy.json`、EXP-008）であり、本変更は**将来の Hanoi 実行と L2 の V(x) モデリングを正す**ためのもの。

検証・進展する仮説：H5（Tc2 再フィット）、H6（崩壊様式の再解釈）、H3/H4（V(x) 地形が L2 モデリングの基盤）。

## 2. 物理的要件【physics-agent 担当】

### 2.1 保存則・対称性の要件
- ハノイ graph の自己同型群はペグ置換群 $S_3$（Park arXiv:0809.1179）。初期ペグ A を固定すると残余 $Z_2$（B↔C）対称性。
- 秩序変数 $m$・ポテンシャル $V$ はこの $Z_2$ に対して**不変**でなければならない。現行の C ハードコードは $Z_2$ を明示的に破っており不自然。
- 違法手ペナルティ $\lambda_p \cdot \text{illegal}$ はペグラベル非依存（$Z_2$ 不変）→ **変更不要**。

### 2.2 極限値チェック項目
- $V(\text{init}) = 1$ が厳密に保たれること（$D_B(\text{init}) = D_C(\text{init}) = 2^N-1$、physics-agent 確認済み）。
- $V(\text{full-B}) = V(\text{full-C}) = 0$（二重井戸の底が縮退）。
- $D_B = D_C$ を満たす状態は初期状態ただ一つ（鞍点 = 初期状態、新規鞍点なし）。

### 2.3 スピングラス・Hopfield・RSB との整合性
- 秩序相 = 2つの縮退基底状態 $\{$full-B, full-C$\}$ のいずれかに到達した相（強磁性 Ising の $\pm m$ 縮退と同型）。
- perfect-to-B は秩序相（PM でも SG でもない）に分類されること。
- L2 p-スピンの正解パターン $\xi^1$ は full-B/full-C の縮退ペア2本として扱う（D-2、本仕様の範囲外だが整合させること）。

### 2.4 懸念点・要確認（物理）→ 壁打ち完了（2026-06-05, user 決定）
- **[論点1：確定]** プロンプト（stimulus）は **peg C 提示のまま据え置く**。既存 432 セルとの比較可能性を優先。「モデルには C を指示し、我々は gauge 対称性の下で評価する」という解釈を採用。
- **[論点2：確定]** `get_prompt_from_state` の「remaining moves」は **C-target のまま維持**（stimulus 一貫性）。$V(x)$（physics）用には別途 `_min_moves_from_symmetric`（$\min(D_B,D_C)$）を新設し、prompt 用 `_min_moves_from`（C-target）と分離する。
- **設計原則：stimulus（プロンプト＝C 据置）と physics 評価（goal_reached・$V$＝B/C 対称）を明確に分離する。**

## 4. アルゴリズム仕様【implementation-agent 担当】

### 4.1 擬似コード / フロー

```
対称化のコア：ゴール集合 G = {full-B, full-C}

goal_reached(moves):
    state = initial
    for each step:
        if state in G: return True   # first-passage
        apply move
    return state in G

V(x) = λ_d · min(D_to_B(x), D_to_C(x)) / (2^N - 1) + λ_p · illegal
    D_to_P(x) = 円盤 1..N を単一ペグ P に積むための最短手数（既存 _min_moves_to_peg を P で呼ぶ）

evaluate_state(moves):
    同様に early-break を「state in G」で行う
```

### 4.2 既存コードとの接続点（`envs/hanoi_env.py`）
- `_goal_state`（L32-36）：採点用に full-B・full-C の2状態を持つゴール集合へ拡張（または goal_set プロパティを新設）。プロンプト表示用の goal 文字列は**従来通り C**（論点1の確定次第）。
- `goal_reached`（L129-146）：`state == self._goal_state` を「state が full-B か full-C」に変更。
- `evaluate_state`（L108-127）：early-break 条件を同様に変更。
- `_min_moves_from`（L189-191）：**C-target のまま維持**（prompt 用、stimulus 一貫性）。
- `_min_moves_from_symmetric`（**新設**）：`min(_min_moves_to_peg(state,N,'B'), _min_moves_to_peg(state,N,'C'))` を返す。$V(x)$ 専用。
- `_compute_V`（L193-197）：`_min_moves_from_symmetric` を使用。ペナルティ項は不変。
- `get_prompt`（L61-78）：**変更しない**（stimulus 据え置き、論点1 確定）。
- `get_prompt_from_state`（L80-98）：**変更しない**（remaining は C-target 維持、論点2 確定）。
- `run.py` / `run_local.py`：`env.goal_reached` を単一の真実源として呼ぶため、early_stop="goal_reached"・accuracy は自動で対称化に追従（変更不要の見込み、要確認）。
